# Contributing

Antipode is a solo-authored project maintained by [@mchl-schrdng](https://github.com/mchl-schrdng).

## Issues & Proposals (Welcome)

Bug reports, security disclosures, and feature or sound-design proposals are welcome via [GitHub Issues](https://github.com/mchl-schrdng/antipode-audio/issues). When reporting a bug, please include:

1. Your operating system, Python/`uv` version, and host agent (Claude Code, Codex, Gemini CLI, Antigravity, or OpenCode).
2. The exact CLI command or recipe JSON and seed that reproduces the behavior.
3. The observed output or error message.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md).

## Pull Requests (Closed to External Contributors)

To preserve the project's architecture, deterministic DSP guarantees, and licensing provenance, **external pull requests are not accepted**. All code, synthesis voices, and documentation changes are authored and maintained solely by the project owner.
